# Thivyanath G — Portfolio

Built with React JS using **Flex brand colors** (#009ADD Cerulean, #8ED1FC Malibu, #262626 Mine Shaft).

## Quick Start
```bash
npm install
npm start
```

## Deploy to GitHub Pages
```bash
# 1. Add to package.json:
"homepage": "https://YOUR_USERNAME.github.io/thivy-portfolio"

# Add to scripts:
"predeploy": "npm run build",
"deploy": "gh-pages -d build"

# 2. Install & deploy:
npm install --save-dev gh-pages
npm run deploy
```

## Update & Redeploy
```bash
git add .
git commit -m "your change"
npm run deploy
```
